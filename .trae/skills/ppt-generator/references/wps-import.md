# WPS 导入指南

详细说明如何将生成的PPT文件导入到WPS Office中。

## 方法一：直接打开 PPTX 文件

### 步骤

1. **打开 WPS 演示**
   - 双击桌面上的 WPS Office 图标
   - 选择"演示"模块

2. **打开文件**
   - 点击"文件" → "打开"
   - 或使用快捷键 `Ctrl + O`
   - 选择生成的 `.pptx` 文件

3. **编辑和保存**
   - 文件将自动转换为 WPS 格式
   - 可以直接编辑
   - 保存时选择 `.pptx` 或 `.dps` 格式

### 注意事项

- WPS 完全兼容 `.pptx` 格式
- 字体可能需要调整（如果使用了特殊字体）
- 动画效果保持兼容

---

## 方法二：从 HTML 转换

如果生成了 HTML 格式的演示文稿：

### 步骤

1. **在浏览器中打开 HTML 文件**
   - 双击 HTML 文件
   - 或拖拽到浏览器窗口

2. **打印为 PDF**
   - 按 `Ctrl + P` 打开打印对话框
   - 选择"另存为 PDF"
   - 选择横向布局
   - 保存 PDF 文件

3. **在 WPS 中导入 PDF**
   - WPS 演示 → 文件 → 打开
   - 选择 PDF 文件
   - WPS 会自动转换为可编辑的幻灯片

### 替代方案：使用截图

1. 在浏览器中全屏显示 HTML 演示
2. 按 `F11` 进入全屏模式
3. 每页按 `Print Screen` 截图
4. 在 WPS 中粘贴到幻灯片

---

## 方法三：使用 WPS 模板替换

### 步骤

1. **打开 WPS 模板库**
   - WPS 演示 → 新建
   - 点击"模板"标签
   - 搜索相似风格的模板

2. **选择模板**
   - 选择与生成 PPT 风格相近的模板
   - 点击"立即使用"

3. **替换内容**
   - 将生成的文字内容复制到模板中
   - 调整布局和样式

## WPS 格式兼容性

### 支持的格式

| 格式 | 说明 | 兼容性 |
|------|------|--------|
| `.pptx` | PowerPoint 2007+ | 完全兼容 |
| `.ppt` | PowerPoint 97-2003 | 完全兼容 |
| `.dps` | WPS 原生格式 | 完全兼容 |
| `.pdf` | PDF 文档 | 可导入转换 |
| `.odp` | OpenDocument | 基本兼容 |

### 功能兼容性

| 功能 | python-pptx | WPS 兼容 |
|------|-------------|----------|
| 文本框 | ✓ | ✓ |
| 图片 | ✓ | ✓ |
| 形状 | ✓ | ✓ |
| 表格 | ✓ | ✓ |
| 图表 | ✓ | ✓ |
| 动画 | 部分 | 需手动调整 |
| 母版 | ✓ | ✓ |
| 主题 | 部分 | 需调整 |

## 常见问题解决

### 问题1：字体显示异常

**解决方案：**
1. 在 WPS 中选择"设计" → "字体"
2. 选择"替换字体"
3. 将特殊字体替换为常用字体

### 问题2：布局错位

**解决方案：**
1. 检查幻灯片尺寸设置
2. WPS 默认使用 16:9 比例
3. 设计 → 幻灯片大小 → 标准 (4:3) 或宽屏 (16:9)

### 问题3：颜色差异

**解决方案：**
1. 检查颜色模式（RGB vs CMYK）
2. python-pptx 使用 RGB 颜色
3. 在 WPS 中手动调整颜色值

### 问题4：动画丢失

**解决方案：**
1. python-pptx 不支持复杂动画
2. 在 WPS 中手动添加动画效果
3. 选择"动画" → "添加动画"

## 最佳实践

### 生成 PPT 时

1. **使用标准字体**
   ```python
   FONT_FAMILY = '微软雅黑'  # 或 'Arial', '宋体'
   ```

2. **使用标准尺寸**
   ```python
   prs.slide_width = Inches(13.333)  # 16:9 宽屏
   prs.slide_height = Inches(7.5)
   ```

3. **使用安全颜色**
   ```python
   # 避免过于鲜艳的颜色
   PRIMARY = RgbColor(0, 82, 147)    # 深蓝
   SECONDARY = RgbColor(0, 123, 194)  # 浅蓝
   TEXT = RgbColor(51, 51, 51)        # 深灰
   ```

### 在 WPS 中编辑时

1. **保存为 .pptx 格式**
   - 保持与其他 Office 软件的兼容性

2. **嵌入字体**
   - 文件 → 选项 → 保存
   - 勾选"将字体嵌入文件"

3. **检查兼容性**
   - 文件 → 信息 → 检查问题
   - 选择"检查兼容性"
