## 1. 项目概述

### 1.1 项目背景

数维数据管家系统是一款 **SaaS 化数据资产评价平台**，旨在为企业提供专业、权威、可落地的数据资产评估服务。系统基于国家数据要素市场化政策，结合《数据安全法》《个人信息保护法》《企业数据资源相关会计处理暂行规定》等法规，构建了一套完整的数据资产评价体系。

### 1.2 升级目标

| 维度 | V1.0 | V2.0 |
|------|------|------|
| 定位 | 数据评估工具 | **数据资产决策平台 + 金融基础设施** |
| AI能力 | 辅助生成报告 | **AI核心驱动** |
| 决策能力 | 规则评分 | **规则 + AI决策 + 政策匹配** |
| 数据价值 | 存储 | **资产化 + 商业化** |
| 商业模式 | 评估服务 | **VIP + 评级/融资/入表** |

### 1.3 核心升级方向

```
V1.0                              V2.0
┌─────────────────┐              ┌─────────────────┐
│  数据评估工具     │     →       │  数据资产决策平台  │
│  + AI辅助        │              │  + AI核心驱动    │
│  + 静态报告      │              │  + 智能决策引擎   │
│                 │              │  + 动态报告      │
└─────────────────┘              └─────────────────┘
```

### 3.1 新增功能清单

### 3.2 功能详细说明

#### NF1: AI编排层（核心升级）

```
用户请求
    ↓
AI Orchestrator
    ├── 模型选择（OpenAI / DeepSeek / 本地模型）
    ├── Prompt选择（模板系统）
    ├── RAG知识检索（ChromaDB）
    └── 输出控制（结构化JSON）

实现：
✅ 支持多模型切换
✅ 支持不同客户定制报告
✅ 支持A/B测试
✅ 支持Prompt版本管理
```

#### NF2: 数据资产决策引擎（V2核心）

```
输入：企业数据情况 + 评估结果
    ↓
决策引擎：
- 政策匹配（入表政策、融资政策）
- 风险判断（合规风险、经营风险）
- 资产分类（可交易、可质押、可入表）
- 可入表判断（会计准则匹配度）
    ↓
输出：
- 入表建议（是否入表、入表价值）
- 改进路径（分步骤指导）
- 融资建议（质押额度、授信建议）
```

#### NF3: 企业对标系统（数据壁垒）

```
evaluation_results
    ↓
标签系统（行业 / 风险 / 成熟度）
    ↓
统计分析
    ↓
输出：
- 行业排名（本企业在他业中的位置）
- 超越比例（超越多少同类企业）
- 同类企业对比（标杆企业分析）
```

#### NF4: 报告异步生成

```
用户提交评估
    ↓
立即返回 report_id（前端可轮询进度）
    ↓
消息队列（Celery）
    ↓
报告生成服务（PDF / AI分析）
    ↓
通知用户（WebSocket / 轮询）
    ↓
用户查看 / 下载
```

#### NF5: 数据资产入表服务

```
入表评估：
- 数据资源会计准则匹配度
- 初始确认条件检查
- 成本归集分析
- 价值评估建议

生成文档：
- 入表操作指引
- 审计材料清单
- 会计分录建议
```

### 7.2 关键设计说明

#### 7.2.1 垂直切片架构（modules/）

每个业务模块都是独立的垂直切片，包含：
- `model.py` - 数据模型
- `schema.py` - Pydantic schemas
- `service.py` - 业务逻辑
- `repository.py` - 数据访问
- `engine/` - 可插拔引擎（仅核心模块）

#### 7.2.2 AI编排层设计

```python
# modules/ai/orchestrator.py
class AIOrchestrator:
    def __init__(self, db: Session):
        self.providers = ProviderRegistry()  # 多模型注册
        self.prompt_manager = PromptManager(db)  # Prompt管理
        self.rag_engine = RAGEngine()  # RAG引擎
        self.output_parser = OutputParser()  # 输出解析

    async def generate_report(self, context: ReportContext) -> ReportResult:
        # 1. 选择模型
        provider = self.providers.select(context)
        # 2. 构建Prompt
        prompt = self.prompt_manager.build(context)
        # 3. RAG增强
        context = await self.rag_engine.enhance(context)
        # 4. 调用模型
        raw_output = await provider.generate(prompt, context)
        # 5. 结构化输出
        return self.output_parser.parse(raw_output)
```

#### 7.2.3 决策引擎设计

```python
# modules/decision/service.py
class DecisionService:
    async def make_decision(self, evaluation_result: EvaluationResult) -> DecisionResult:
        # 1. 政策匹配
        policies = await self.policy_engine.match(evaluation_result)
        # 2. 资产分类
        classification = await self.asset_classifier.classify(evaluation_result)
        # 3. 生成建议
        recommendations = await self.recommendation_engine.generate(evaluation_result)
        # 4. 生成解释
        explanation = await self.explainability.explain(classification, recommendations)
        return DecisionResult(policies, classification, recommendations, explanation)
```
